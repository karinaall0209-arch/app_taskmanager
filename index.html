Часто задаваемые вопросы (Справка)

Как отметить задачу выполненной?

На текущем этапе верстки интерфейс статичен. В следующей лабораторной работе с подключением JavaScript появится возможность кликать по задаче для смены статуса.

Куда сохраняются введённые данные?

Пока данные не отправляются на сервер. Позже мы подключим LocalStorage для хранения данных прямо в браузере.
